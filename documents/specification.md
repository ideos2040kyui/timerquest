# TodoQuest アプリケーション仕様書（2025年6月2日更新）

## 1. アプリケーション概要

TodoQuestは、ユーザーごとにタスク管理・タイマー・経験値（XP）を組み合わせた成長型タスク管理Webアプリケーションです。ユーザーはタスクを登録し、タイマーで集中作業し、完了ごとにXPを獲得できます。スマホに最適化された形、ブロックごとに分かれた直感的なUIで実装します。

---

## 2. 技術スタック
- Next.js（App Router）
- TypeScript
- サーバ側データ: userdata.json
- APIルート: /api/userdata
- PWA/スマホUI対応

## 3. 主要機能

### 3.1 ユーザー認証・メイン画面
- ユーザー名を入力し、userdata.jsonに登録されているユーザであればメイン画面に遷移。
- 以前ログインしていたユーザがいれば（同じ端末でキャッシュに前回ログインユーザが残っていれば）入力せずそのユーザ画面に最初から遷移。
- メイン画面では、最上部にタイトルロゴ、ユーザ名、レベル、次のレベルまで必要なXP、その下に「タスクをこなして強くなろう！」という文字とinfoボタン、infoボタンを押すとタスク登録・レベルアップの説明が展開表示される。その下にタスク登録フォーム、タスク一覧が表示される。タスク一覧はスクロール可能。

### 3.2 タスク登録・保存・削除
- タスク名・所要時間（分）を入力してタスクを登録。
- 登録・削除はサーバ（/api/userdata経由でuserdata.json）に保存。
- タスクは削除しない限り何度でもタイマーとして利用可能。
- タスク登録フォームは「タスク名」「所要時間（分）」が横並び、その下に「追加」ボタンが右端に表示される。

### 3.3 タイマー起動・遷移
- タスクの「タイマー開始」ボタンでタイマーページ（/timer/[id]）に遷移。
- タイマーページでは残り時間と中断ボタンが表示され、1秒ごとに減少。
- タイマーは中断が可能。

### 3.4 タイマーの中断
- タイマー中断時は、残り時間（timeRemaining）と中断時刻（lastPaused）をサーバに保存、メインページに戻る。
- 再度タイマーを開始する際、メインページでは「タイマー開始」の代わりに「途中から再開」「最初から開始」の2択を表示。
- 途中から再開時はlastPausedから、最初から開始時はduration*60秒からスタート。
- 「最初から開始」ボタンを押すと、timeRemaining/lastPausedをリセットし、即タイマーページに遷移する。
- 「途中から再開」ボタンの下には残り時間（mm:ss形式、例: 0:34）が表示される。

### 3.5 タイマー完了時のXP加算
- タイマーが0になったら、タスクが完了しましたというポップアップと、そのタスクのduration分のXPをユーザーに加算（例：「1 XPを獲得しました」）。
- XPはサーバ（userdata.json）に保存。
- タスクのtimeRemainingとlastPausedはリセットされる。
- タスク自体は削除されず、何度でもタイマー利用可能。

### 3.6 データ保存の一元化
- タスク追加・削除・中断・再開・完了時、必ず/api/userdata経由でサーバに保存。
- XPも同時に保存。

### 3.7 レベルアップ機能
- 全ユーザーはLv1から開始し、最大Lv20まで上がる。
- レベルアップに必要なXPは以下の通り：
  - Lv1→2: 10xp
  - Lv2→3: 20xp
  - Lv3→4: 30xp
  - ...（以降10xpずつ増加）
  - Lv12以降は120xp固定
- レベル・XPはユーザーデータ（UserData型）に保存。
- メイン画面で現在レベルと次のレベルアップまでに必要なXPを表示。
- レベルアップ時の演出や通知は今後の拡張で追加可能。

## 4. データ構造

### 4.1 Todo型
```typescript
interface Todo {
  id: number;
  text: string;
  duration: number;
  timeRemaining: number;
  lastPaused: number | null;
  userName?: string;
}
```

### 4.2 UserData型
```typescript
interface UserData {
  userName: string;
  todos: Todo[];
  xp: number;      // 獲得済みXP
  level: number;   // 現在のレベル
}
```

### 4.3 userdata.jsonの構造
```json
{
  "users": [
    {
      "userName": "Test",
      "todos": [ ... ],
      "xp": 0,
      "level": 1
    }
  ]
}
```

## 5. 画面構成

### 5.1 ユーザー名入力画面（/login）
- ユーザー名を入力し、既存ユーザーならメイン画面へ遷移
- 前回ログインユーザーがいれば自動遷移
- キャッシュユーザーが見つからなかった場合はフォームが表示される

### 5.2 メインページ（/[userName]）
- タスク入力フォーム（「タスク名」「所要時間（分）」横並び＋下段右端に「追加」ボタン）
- タスク一覧表示（削除ボタンは上段右、タイマーボタン群は下段左、何度でもタイマー利用可）
- 各タスクカードの所要時間は「1分」のようにシンプルに表示
- 「途中から再開」ボタンの下に残り時間（mm:ss）を表示
- XP・レベル表示（「ユーザー名 Lv.1 次Lvまで ... XP」のように1行で表示）
- infoボタンで説明展開
- ユーザー名をタップするとユーザー切り替え（ログイン画面へ遷移＆キャッシュクリア）

### 5.3 タイマーページ（/timer/[id]）
- タスク名表示
- タイマー表示
- 中断ボタン
- タイマー完了時はXP獲得ポップアップ
